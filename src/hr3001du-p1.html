HUENÚ HR3001DU

Equipo DTF UV de 320 mm

Stickers transferibles UV para personalización de objetos.

Impresión, curado y laminado integrados para producir aplicaciones DTF UV sobre film AB, listas para transferir sobre vidrio, metal, cerámica, plásticos, madera y productos promocionales.

Sumá personalización UV sin imprimir directamente sobre el objeto

El HUENÚ HR3001DU permite producir transfers DTF UV de alta definición para aplicar sobre distintas superficies, ampliando la oferta de productos personalizados, packaging, regalos corporativos y merchandising.

Aplicaciones

Transfers UV para personalizar objetos, envases y superficies rígidas con terminaciones de alto valor.

Oportunidades de negocio

Merchandising corporativoRegalos empresariales y objetos promocionales.
Packaging personalizadoEnvases, cajas, bolsas y presentaciones de marca.
Regalería y souvenirsProducción flexible para fechas especiales y venta minorista.
Objetos rígidosAplicaciones sobre vidrio, metal, cerámica, plástico y madera.
